# Compact Shop checks

This change starts at owner-merged main `ed4092d99b4f2092d27021a8f2df2902122a44be` (build269). The adjacent [baseline.json](baseline.json) was captured from that revision's Git blobs, independently of current working-file edits. It contains 1,617 shipping art hashes, 51 game source hashes, all eight bundles, 35 ownership IDs and individual prices/grants, cash and boost offers, and 440 complete ownership quote cases. The older Shop-refresh baseline is historical evidence for an earlier change and is not the preservation target here.

The latest accepted layout uses one horizontal row of four daily items, with no vertical rail or category filter. The row belongs to the compact viewer; current details remain at its upper left. This supersedes the earlier separate suit/gear rails and the temporary three-day design preview. The cart follows the viewer; bundles appear before boosts and Stardust. Boost cards use the owner's concise descriptions, with no explanatory paragraph between the boost rows and Stardust. Selecting an external helmet while a fixed-head suit is previewed should show that helmet on a compatible body, without adding the preview body to the cart or changing equipment.

The latest accepted roster supersedes four pinned premium suits: two suits per day, with one available fixed-price premium and one cheaper suit, falling back to two cheaper suits when premiums are exhausted. The two normal gear slots contain one helmet plus one PAL, or two helmets on a zero-PAL day. If suit stock is scarce, gear can fill spare space up to its category limits (two helmets and one PAL); for example, one remaining suit plus three gear items can fill four cards. Fully exhausted categories leave fewer than four items. Gear prefers compatibility/shared-kit styling before date-random choices, with a suit's coordinated PAL preferred over a helmet's. Shared suit/helmet ownership IDs appear once. Bandit, Noodle and Quill (`raccoon`, `ferret`, `hedgehog`) stay login rewards and never enter paid daily stock; the Critter Pack remains in the registry with unchanged grants, but is excluded from live paid offers.

The initial container run of `test-helmet-animation.mjs` failed while running `git archive`, before any renderer comparison. Its shared Git directory referred to an alternate object store by a Windows absolute path that Linux could not resolve. Both pinned revisions already existed locally.

# Shared chrome rule (owner)

Same menus/modes language everywhere. One page must not look like a new style.
Examples: back always purple (ac-backbtn), launch/primary always blue (ac-primary), shared Fraunces titles + Figtree UI, shared sizes/radii.

## Canonical tokens
- Back: .ac-backbtn (purple circular chevron via header())
- Primary/Launch: .ac-primary #4ab4ff / hub .t-launch blue
- Secondary: .ac-ghost navy border #2a3454 r16
- Help: .ac-helpdot
- Titles: Fraunces 800; Kickers: .ac-kicker; Chrome labels UPPERCASE

## Debris Field breaks (Launch to run + Loadout SHIP)
- .ac-workshop-launch cyan gradient → alias .ac-primary
- .ac-workshop-exit custom → .ac-ghost + UPPERCASE
- Guide text → .ac-helpdot
- lavender kickers → .ac-kicker
- Fraunces 600 cream titles → Fraunces 800 like header()
- Do NOT invent a new Debris Field brand hue
- Functional flight control colors (Throttle/Dive/Lunge) can stay

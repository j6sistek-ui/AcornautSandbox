# Ludo power-up generation archive

Everything the Ludo MCP experiment produced for the pickups, banked so
nothing depends on Ludo's 7-day URLs or an ephemeral session:

- `*-v2-frames/`, `shield-b-frames/`: the APPROVED 16-frame cycles that
  ship in docs/art (acorn, golden, frozen wiggle-only, shield B).
- `acorn-frames/`, `acorn-a-frames/`, `*-sheet.webp`, `*-anim.gif`:
  earlier takes and preview material, kept for reference.
- `8bit-*.webp`: pixel-art candidates for the arcade set (A/B pairs).
- `wormhole-*.webp`, `blackhole-*.webp`: concept candidates for the
  all-new vortex art (A/B/C), awaiting the owner's pick, then animation.
- `specials-candidates.png`, `powerup-candidates.png`,
  `shield2-candidates.png`: the review sheets as sent.

Generated 2026-08-22 via Ludo MCP from owner-approved prompts; style
anchors were the shipping game sprites.
